## 💡 Overview & Market Insights 📈

> [!NOTE]
> **Market Size & Structure**: The global **Video Game Subscription & Cloud Gaming market** is estimated at **$15.2 Billion (2026)** and projected to reach **$30+ Billion by 2030**.
> The market is **moderately fragmented** between commercial category leaders (Microsoft Xbox Game Pass, Sony PlayStation Plus, NVIDIA GeForce NOW) controlling primary game licensing, and a rapidly expanding **open-source ecosystem** (Sunshine, Moonlight, Heroic, Playnite) delivering decentralized cloud gaming infrastructure and unified game launchers.

## 🔓 Open-Source GitHub Projects & Self-Hosted Infrastructure ⚡

| **[Heroic Games Launcher](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher)** | [<img src="https://img.shields.io/github/stars/Heroic-Games-Launcher/HeroicGamesLauncher?style=social&color=white" alt="Heroic Stars"/>](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/stargazers) | TypeScript, Electron, React | **Cross-platform launcher for Epic, GOG, and Amazon Games** on Linux, macOS, and Windows (Steam Deck optimized). |
| **[Lutris](https://github.com/lutris/lutris)** | [<img src="https://img.shields.io/github/stars/lutris/lutris?style=social&color=white" alt="Lutris Stars"/>](https://github.com/lutris/lutris/stargazers) | Python, GTK3, Wine | **Open-source gaming platform for Linux**. Preserves games across Steam, GOG, Windows titles via Wine, and emulators. |
| **[Legendary](https://github.com/derrod/legendary)** | [<img src="https://img.shields.io/github/stars/derrod/legendary?style=social&color=white" alt="Legendary Stars"/>](https://github.com/derrod/legendary/stargazers) | Python, CLI | **CLI open-source replacement for Epic Games Launcher**. Lightweight tool to download and launch Epic games. |
| **[Cloudy Pad](https://github.com/PierreBeucher/cloudypad)** | [<img src="https://img.shields.io/github/stars/PierreBeucher/cloudypad?style=social&color=white" alt="Cloudy Pad Stars"/>](https://github.com/PierreBeucher/cloudypad/stargazers) | Go, Terraform, AWS/GCP | **Self-hosted cloud gaming platform on cloud spot instances**. Open-source alternative to GeForce NOW (~$15/mo pay-as-you-go). |
| **[Cartridges](https://github.com/kra-mo/cartridges)** | [<img src="https://img.shields.io/github/stars/kra-mo/cartridges?style=social&color=white" alt="Cartridges Stars"/>](https://github.com/kra-mo/cartridges/stargazers) | Python, GTK4, Libadwaita | **GTK4 Libadwaita game launcher for GNOME/Linux**. | **[CloudMorph](https://github.com/giongto35/cloud-morph)** | [<img src="https://img.shields.io/github/stars/giongto35/cloud-morph?style=social&color=white" alt="CloudMorph Stars"/>](https://github.com/giongto35/cloud-morph/stargazers) | Go, WebRTC, Wine | **Decentralized, browser-based cloud gaming service**.
